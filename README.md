# James Nowlin — Real Estate (v3)

Single-page site for James Nowlin, SC License #129577, Realty ONE Group Reside (Lexington, SC).
Built by Carolina Redesign on the gold/charcoal design.

- `index.html` — the whole site (Tailwind CDN). Listings live in the `midlandsListings` array.
- `img/<MLS#>.webp` — first MLS photo for each listing, from James's Realty ONE Group
  featured-listings and sold-properties pages (CMLS, October 2026).
- Forms have no backend; they open a pre-filled email to office@jamesnowlinrealtor.com.

To refresh listings: update the array and add/remove `img/<MLS#>.webp`. Keep the
"Listing courtesy of" brokerage on every card.

Live: https://jimmyardis.github.io/James-Nowlin3/
